# DIRECTION.md — JossyShield Security Services

## Step 0: The Brief
- **App**: JossyShield Security Services — Modern Commercial Security, Tactical Training, and Risk Consultancy Portal with Service Marketplace & Security Talent Pool.
- **Audience**: Corporate clients, commercial property managers, industrial facilities, event organizers, and professional security personnel seeking vetting and deployment.
- **Core Action (First 10s)**: Request a rapid security quote/service through the interactive category marketplace, or explore verified guarding and tactical consultancy capabilities.
- **Feel**: Fortified, elite, disciplined, authoritative, and technologically modern. (Reference: Swiss defence engineering, high-end private aviation, matte titanium timepiece).
- **Brand Colors**: Gray, black, and electric blue (`#0a0b0e` obsidian black, `#12151c` deep slate, `#1e222d` control gray, `#2563eb` tactical blue).
- **Quality Standard**: 5/5 Apple Design Award rubric compliance — zero AI slop, no generic card stacks, real typography hierarchy, glass navigation, responsive micro-interactions.

## Refused Defaults (Anti-Slop)
- Refuse generic neon shield clipart or low-res padlock stock imagery.
- Refuse generic purple-to-blue SaaS gradients.
- Refuse flat, unstyled form inputs with boring standard labels.
- Refuse fake generic placeholder copy ("Lorem ipsum", "John Doe"); use authentic security protocols, real personnel categories, and vetted compliance metrics.

## Design Tokens
- **Background Ground**: Dark (`#0a0b0e`, `#12151c`)
- **Card / Surface**: `#181c26` with 1px border `#2a3242` and subtle ambient glow.
- **Accent**: Precision Tactical Blue (`#3b82f6` text/glow, `#2563eb` primary buttons, `#1d4ed8` hover).
- **Typography**:
  - Display / Headings: `Inter`, `system-ui`, `-apple-system`, geometric bold with tight tracking (`tracking-tight`).
  - Body: Precision sans with generous line-height (`leading-relaxed`) and high-contrast readable silver (`#cbd5e1`).
  - Data / Metrics / Reference IDs: Monospace `JetBrains Mono` / `SF Mono` for reference IDs (`JS-REQ-XXXXX`).
- **Signature Interaction**:
  - Dynamic Service Request Marketplace Configurator: Interactive category pills that smoothly animate the form parameters (Personnel Count, Shift Hours, Risk Tier, Immediate Deployment Toggle) with instant reference number generator.

## 5/5 Rubric Alignment
1. **Concept on the Pixel**: The interface radiates high-readiness tactical reliability with dark glass finishes, crisp tabular specs, and real security protocols.
2. **Not Category Average**: Avoids dated 2000s security agency layouts; presents a modern technology-enabled defence firm.
3. **Hierarchy**: High-impact bold value proposition lands first, followed by clear tactical service pillars and instant quote actions.
4. **Craft Details**: Subtle status indicators, live badge pulses, verified credentials, and real downloadable PDFs/brochures.
